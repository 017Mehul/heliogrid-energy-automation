# HelioGrid Energy — Lead to Booked Call

A polished, interactive portfolio case study demonstrating an AI-powered solar lead automation workflow.

## Highlights

- Premium responsive landing page inspired by the HelioGrid case study
- Interactive lead intake form
- Simulated AI qualification and lead scoring
- Smart representative routing
- CRM sync, Slack notification, SMS follow-up and booking-ready states
- Vercel-compatible serverless API endpoint

## Tech

- HTML5, CSS3 and vanilla JavaScript
- Responsive CSS Grid and Flexbox
- Vercel serverless function

## Run locally

```bash
npx serve .
```
